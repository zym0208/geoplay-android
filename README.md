# GeoPlay (JavaBean)

Android location-based game with routes, quizzes, friends, favourites and score views. Java Activities, Volley HTTP requests, JSON and RecyclerView adapters.

## Snapshot status

Local Android working files. Missing root Gradle files supplemented from the available school ap110 archive; compatibility has NOT been build-verified. School API availability and credentials require configuration.
